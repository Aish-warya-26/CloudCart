# CloudCart

CloudCart is a cloud-native E-Commerce application developed using a Microservices Architecture.

## Technologies

- Flask
- MongoDB
- Docker
- Docker Compose
- Kubernetes
- GitHub Actions
- GitHub
- Postman

## Services

- Product Service
- Cart Service
- Order Service

## Features

- REST APIs
- Containerized Services
- MongoDB Database
- CI/CD Pipeline
- Kubernetes Deployment
- Docker Compose
